# 豆包炫酷启动器 · 小白版

一个全屏启动动画，打开豆包之前先放一段炫酷动画，带配音和立绘。

## 📦 下载

- 安装包（推荐，解压即用）：[doubao-launcher.zip（2.6 MB）](https://github.com/MZXH1945/doubao-cool-launcher/releases/download/v1.3.0/doubao-launcher.zip)
- 源码：`git clone https://github.com/MZXH1945/doubao-cool-launcher.git`

---

## 🚀 怎么用？

### 第一次用（只做一次）
1. 安装 Python 3.8 或更高版本：https://www.python.org/downloads/
   - ⚠️ 安装时一定要勾选 **"Add Python to PATH"**（把 Python 加到环境变量）
2. 解压本压缩包到任意文件夹

### 日常使用
**双击 `双击启动.bat`** 就行了！

第一次运行会自动安装依赖，以后就直接启动动画了。

---

## 🎨 怎么改样式？

**双击 `打开设置.bat`**，会自动打开一个网页设置面板：

- **配音**：机械女声 / 墨者新鸿男声 / 俄语版
- **Logo 颜色**：红色 / 黄色
- **立绘款式**：5 款人物可选，也可以关掉
- **主色调**：随便选颜色
- **文字内容**：大标题、副标题、机构名、欢迎语都能改

改完点 **"保存设置"** 就生效了，不用碰代码。

---

## 🖼️ 怎么换自己的立绘？

把你喜欢的图片（最好是透明背景的 PNG/WebP）命名为：
```
custom-mascot.webp
```
然后丢进 `lib/assets/` 文件夹里，再到设置面板里选"自定义立绘"就行。

---

## 🎵 怎么换自己的配音？

内置三套配音（各 6 句）：`line` 机械女声、`line-xh` 汉语男声、`line-ru` 俄语版。

想换成自己的声音，**同名覆盖就行**——把 mp3 按下面的名字放进 `lib/assets/` 文件夹：

```
line-1.mp3 ~ line-6.mp3        机械女声（6 句）
line-xh-1.mp3 ~ line-xh-6.mp3  汉语男声（6 句）
line-ru-1.mp3 ~ line-ru-6.mp3  俄语版（6 句）
```

代码会优先读文件夹里的 mp3，读不到才用内置的打包数据，所以同名替换立刻生效，不用改代码。

## ❓ 常见问题

**Q：双击启动后黑窗口一闪就没了？**
A：说明 Python 没装好，或者没勾选"Add Python to PATH"。重装一下 Python 试试。

**Q：动画播完了豆包没打开？**
A：说明豆包不在默认安装位置。打开 `doubao_launcher.py`，找到 `DOUBAO_PATHS`，改成你自己的豆包路径。

**Q：设置改了没生效？**
A：刷新一下页面，或者重新打开设置面板，确认点了"保存设置"。
